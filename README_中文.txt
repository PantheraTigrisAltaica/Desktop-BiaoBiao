Tiger Pet · 第一只老虎（含喂食互动）

原有五个动作：走路、休息、挥爪、玩球、抖水，行为不变。

喂食互动（只能双击老虎触发，不在右键菜单里，也不参与自动切换和单击轮换）
  1. 在「走路 / 休息 / 挥爪」时双击老虎 → 老虎进入「等肉」，原地等着
     （玩球、抖水时双击没有反应）
  2. 3 秒内再双击一次 → 投喂成功，老虎「吃肉」（20 帧，约 2.4 秒）
  3. 3 秒内没有再双击 → 老虎很生气，「吼叫」并发出虎啸（约 2.5 秒）
  吃肉或吼叫结束后，老虎回到双击前的动作；如果原来在走路，会按原方向继续走。

  • 等肉期间可以拖动老虎，倒计时照常进行。
  • 等肉期间如果从右键菜单选了别的动作，本次喂食取消，老虎不会吼叫。
  • 暂停期间倒计时会顺延，恢复后才继续计时。
  • 吃肉、吼叫过程中的双击会被忽略。

单击的变化
  为了区分单击和双击，单击后要等一个系统双击间隔（Windows 默认约 0.5 秒）
  才切换到下一个动作，所以单击会比以前慢半拍。这个延迟只在配置了双击互动的
  宠物上生效；第二只老虎没有互动，单击仍然立即切换。

声音
  右键菜单里新增「声音」开关，默认开启，关闭后吼叫不出声。
  虎啸截自你提供的视频第 12.75–14.55 秒（画面中老虎正张大嘴），
  开头加了 0.5 秒静音，使吼声正好在吼叫动画第 3 帧张嘴时响起；
  峰值压到 60%，避免突然太吵。
  注意：原视频的音频本身有约 1% 的削波，事后无法完全修复。
  这一版的虎啸做了人声抑制：追踪虎啸自身的谐波（基频约 185Hz）只保留这些频率，
  其余声音大幅压低。实测混入的男声约压低 14dB、女声/童声约压低 10dB，
  压低了混在其中的人声，但与虎啸谐波重合的部分无法去除，虎啸的沙哑气声也会略减。

素材处理
  • 等肉、吃肉原素材里老虎朝左，已预先水平翻转成朝右，与其他动作一致，
    否则老虎往右走时一双击就会突然掉头。
  • 吃肉第 13 帧有灰色背景残留，已清理；飞来的肉保留。
  • 三个动作都做了逐帧配准和贴地，大小按走路/休息/挥爪可见面积的中位数统一。

这一版修复的问题
  • 走路时双击老虎没有反应（休息、挥爪时正常）。原因是系统判断双击时，比较的是
    两次点击在窗口里的位置；老虎走路时窗口每秒移动约 78 像素，两次点击之间窗口
    已经挪了约 20 像素，系统就认为是点在了两个不同的地方，不算双击，第一下还会
    被当成单击切换动作。现在程序改用屏幕坐标自己判断双击，窗口移动不受影响。
    另外，点第一下时老虎会先停下脚步（最多约半秒），等确定不是双击再继续走，
    这样第二下不会因为老虎走开而点空。
  • 老虎朝左时（画面镜像），切换动作身体会横跳：原来程序用的是未翻转时的
    身体中心。影响最大的是走路切到等肉，横跳 26.5 像素；原有的走路切挥爪
    也一直有约 10 像素的横跳。现在已修复。

框架
  这一版已迁移到与第二只老虎相同的框架：动作、尺寸、菜单文字、喂食规则
  全部在 assets/actions.json 里，Windows 和 Mac 两个版本共用。
  喂食规则在 "interaction" 一节：触发的动作列表、等待秒数（timeout，当前 3 秒）、成功/失败动作。

启动（Windows）
  双击 Run_Tiger_Pet.cmd。不显示时用 Run_Tiger_Pet_DEBUG.cmd，
  所有输出会写进 TigerPet_launch.log。
